0|# Как клиент находит файл
1|• **Порядок поиска:** ezQuake ищет в `id1`, затем в `ezquake`, затем в `qw`. Побеждает файл из более поздней папки.
2|• **Отдельные файлы важнее:** в папке игры отдельный файл побеждает тот же файл внутри `.pak` или `.pk3`.
3|• **Форматы изображений:** клиент пробует `.tga`, затем `.png`, `.jpg` и `.pcx`. Побеждает первый найденный, поэтому `.png` рядом с `.tga` с тем же именем никогда не используется.
4|• **Ссылки:** текстовый файл `<name>.link` может указывать на другое изображение (его первая строка — путь внутри `textures/`).
5|• **Специальные символы:** в именах файлов `*` превращается в `#`. Поэтому текстуры воды, лавы и слизи называются, например, `#water1.png`.
6|• **Светящиеся слои:** файлы `_luma` добавляют светящийся слой (fullbright). Их используют только скины моделей и текстуры карт и ящиков; `_glow` никогда не загружается.
7|• **Регистр букв:** в Linux имена чувствительны к регистру, поэтому приложение всегда копирует файлы в игру в нижнем регистре.
8|• **Подпапки:** подпапки внутри папки текстур не загружаются (поэтому папки «original» ни на что не влияют).
9|# Типы ресурсов, показываемые по умолчанию
10|• **Models** (`qw/textures/models`): `<model>_<skin>`, например `armor_0`, `armor_1`, `armor_2` (у брони 3 скина, у большинства моделей — 1). `_luma` по желанию. Анимированные скины используют `<model>_<skin>_<frame>`; простые предметы — `simple_<model>_<n>`. `eyes.mdl` никогда не использует заменённые скины.
11|• **BModels** (`qw/textures/bmodels`): ящики со здоровьем и патронами (`maps/b_*.bsp`), названные по текстурам внутри них: `med3_0`, `med100`, `+0_med25` (кадры анимации сохраняют префикс `+0_`), `shot0sid`, `rockettop`… Простые предметы: `simple_b_bh100_0`.
12|• **HUD** (`qw/textures/wad`): изображения строки состояния из `gfx.wad`, фиксированный список: `num_0`..`9`, `anum_0`..`9`, `sb_*`, `face1`..`5`, значки оружия `inv_*`, `ibar`, `sbar`, `scorebar`, `disc`, `ram`, `net`, `turtle`, `backtile`. Никогда не загружаются: `anum_colon`, `inv_rocket`, `conchars`.
13|• **Tracker** (`qw/textures/tracker`): значки оружия для frag tracker. Имена берутся из строк WEAPON_CLASS в `fragfile.dat`, например `\rl\` загружает `textures/tracker/rl`.
14|• **Particles** (`qw/textures/particles`): один файл, `particlefont`: атлас 256×192, разрезаемый на частицы крови, дыма, лавы, вспышки, пузыря и искры.
15|# Другие типы ресурсов (по умолчанию скрыты, включите их в настройках)
16|• **Crosshairs** (`qw/crosshairs`): любое имя изображения, выбирается через `crosshairimage`.
17|• **Skyboxes** (`qw/env`, а также `gfx/env`): `<sky>` плюс `rt`, `bk`, `lf`, `ft`, `up`, `dn` (все 6 сторон). Файл `_wind.cfg` неба читается только из `gfx/env`.
18|• **Gfx** (`qw/gfx`): фон консоли (`conback` или имя из `scr_conpicture`), изображения меню и курсор. Файл `gfx/conback.lmp` должен существовать, иначе игра не запустится.
19|• **Charsets** (`qw/textures/charsets`): шрифты консоли, любое имя, выбирается через `gl_consolefont`.
20|• **Levelshots** (`qw/textures/levelshots`): картинка загрузки каждой карты, названная по имени карты.
21|• **Skins** (`qw/skins`): скины игроков, любое имя. Пробует `.tga`, `.png`, `.jpg`, затем `.pcx`; иначе используется `base`.
22|• **Progs** (`qw/progs`): модели и спрайты, любое имя. Файл `.md3` с тем же именем заменяет `.mdl`.
23|# Не управляется приложением
24|• **Sounds** (`qw/sound`): точные пути с подпапками; `.ogg` никогда не заменяет запрошенный `.wav`.
25|• **Maps** (`qw/maps`): `<map>.bsp` и дополнительные файлы; ящики с предметами (`b_*.bsp`) тоже здесь.
26|• **Lits и Locs** (`qw/lits`, `qw/locs`): цветное освещение (`<map>.lit`) и названия мест для командной игры (`<map>.loc`).
27|• **Map textures** (`qw/textures/<map>/`): ищутся по карте, затем по группе карт, затем в `textures/`.
